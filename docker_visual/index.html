    Lv1全体像：この1枚から始める

    あなたが docker コマンドを打つと、あなたの PC（Docker ホスト）の中で、6つの部品が働きます。いまは、輪郭（点線）だけです。

    • ホストOS：コンテナの土台
    • Docker Engine：命令を受けて、作る係
    • イメージ：コンテナの元
    • コンテナ：動いているもの
    • ネットワーク：コンテナの通り道
    • データの置き場所：消したくないデータ

    PC の外にはレジストリ（イメージの保管場所）があります。ここから、1つずつ中身を足していきます。スクロールしてください。

    Lv2ホストOS：コンテナが借りる土台

    OS は「カーネル（心臓部）」と「ユーザーモードのファイル（その上で動く部品）」でできています。

    コンテナは、あとで見るように、このうちカーネルを借りて動きます。だから、土台の OS の種類が大事です。

    Lv3Docker Engine：命令を受けて、作る係

    あなたの命令は、docker → API → dockerd の順に流れます。実際の作業をするのは dockerd（デーモン）。ビルド・実行・レジストリとのやり取りを担当し、イメージ・コンテナ・ネットワーク・ボリュームを作って管理します。

    Lv4イメージ：コンテナの元

    イメージは、読み取り専用のテンプレートです。複数のレイヤー（層）が積み重なってできていて、作成後は変更できません。

    イメージはレジストリ（Docker Hub など）に保管・配布されます。dockerd が docker pull で取ってきます。

    ここで増えたもの イメージ ＝ レイヤーの積み重ね　／　レジストリ ⇄ イメージ（pull / push）

    Lv5コンテナ：イメージを動かしたもの

    コンテナはイメージから作られます（docker run）。イメージの層（読み取り専用）に、コンテナ専用の書き込み層を1枚足したものです。

    コンテナはカーネルを持たず、ホストOSのカーネルを借りて動きます。アプリと、自分用の OS 部品（ベースイメージ）だけを持っています。

    ここで増えたもの コンテナ ＝ イメージの層（読み取り専用）＋ 書き込み層 ＋ アプリ　※ カーネルは借りる

    Lv6Windowsコンテナ と Linuxコンテナ

    違いは、借りるカーネルの種類です。図の上のスイッチで、Windows コンテナと Linux コンテナを切り替えてみてください。

    • Windows コンテナ：Windows のカーネルを借りる（プロセス分離）。Hyper-V 分離なら、軽量VMの中に専用のカーネルを持つ。
    • Linux コンテナ：Linux のカーネルが必要。Windows PC では WSL 2（Microsoft 製の Linux カーネル）が土台になる。
    ここで増えたもの Linux コンテナの土台 ＝ WSL 2 の Linux カーネル。カーネルが違うものは混ぜられない。

    Lv7ネットワーク：コンテナの通り道

    コンテナは、初期状態でネットワークにつながっていて、外へ出る通信はできます。

    • Windows：既定のネットワークは nat。
    • Linux：既定はデフォルト bridge。公式は「ユーザー定義 bridge のほうが優れている」と明記（名前で通信できる・つないだものだけが通信できる・動いたまま付け外しできる）。
    • 外から中へ入れるには、-p でポートを公開する。
    ここで増えたもの ホスト ＞ ネットワーク ＞ コンテナ。1つのコンテナを複数のネットワークにつなげられる。

    Lv8ボリューム：消えないデータの置き場

    コンテナの書き込み層は、コンテナを消すと一緒に消えます。残したいデータは、コンテナの外に置きます。

    ボリュームは、Docker が管理する置き場です。コンテナの「マウント先」（/data）から見せます。ボリュームはイメージにもコンテナにも属さないので、コンテナを消しても残ります。

    ここで増えたもの コンテナ ← マウント先 ← ボリューム（Docker が管理する領域）

    Lv9bind mount と tmpfs：外に置く、ほかの方法（完成図）

    外に置く方法は、ボリュームのほかに2つあります。

    • bind mount：ホスト上の好きな場所を、そのまま見せる。ホストからも同じファイルを触れる。
    • tmpfs：ホストのメモリ上だけ。ディスクには書かれず、止めると消える。
